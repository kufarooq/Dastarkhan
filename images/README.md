# Images

- `hero.jpg` — the large dining-room photo at the top of the page (landscape, ~1920×1080).
- `background.jpg` — food photo shown behind the About, Menu and Hours sections (landscape, ~1920×1080).
  A dark layer is placed over it so text stays readable. Without it, the purple-gold gradient is used.
- `menu/<dish-id>.jpg` — one photo per dish. The file name must match the dish `id` in `js/menu.js`
  (for example `menu/chicken-karahi.jpg`). Square-ish or 4:3 photos work best.

Until a photo is added, the site shows a placeholder icon in its place.
